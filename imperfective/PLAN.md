## 3 实验 1：设计

### 3.1 任务

| 任务 | 系统提示 | 问题 | 输出 | 读数 |
|---|---|---|---|---|
| **L 标签** | 原论文「You are a strict logician …」（附录 B P1 逐字） | 是否**必然**为真 | True／False／Unknown | 实际生成的标签；标签分数 q（见 3.3） |
| **P-strict** | 同 L | 同 L 的定义文字，但要求报**假设必然为真的机率** | `Probability: NN%` | 报告的机率 |
| **P 直接机率** | 无 | 常识框架：「Using common sense, how likely is it that the following statement is true?」 | `Probability: NN%` | 报告的机率 |
| **M 多估计** | 无 | 同 P | 5 个估计各附权重（δ-NLI 问法与解析 v2） | 加权平均；另报候选层端点质量与加权标准差 |

- **两两对比的含义**：L 对 P-strict 是**两种输出协议**的读数差异：系统提示（含其中要求输出 True／False／Unknown 的句子）、定义文字、解码与输出上限（本次 S3 统一 1024，旧版为 512）都相同，P-strict 在用户消息末尾以「报机率」的指示取代原论文「只回答三个选项之一」的指示；系统与用户指示的冲突是这个协议的一部分，所以不称「单独分离了输出形式」；P-strict 对 P 是**问题框架**的差异（必然 vs 常识可能性），连同系统提示的有无一起变，不称单因素；P 对 M 只差**接口**（一个数 vs 五个加权估计）。每一步都只叫「任务框架下的读数差异」，不称「信念」与「标签」的分离：q 与口述机率都是特定提示下的输出，不是模型内部信念的直接测量。
- **提示**：**Z** 零样本（原论文 P1）；**DAP** 加语言学定义；**CoT** 先分析再作答；**CF** 先列 3 个未达成的情境再作答。L 任务照原论文逐字；P、M 任务的定义段（DAP）放在问题之前，分析与反事实指示（CoT、CF）放在问题之后、作答格式之前（v0.5 修订：指示里要提到「statement」，放在它出现之后读起来才通；逐字题面见 `brief-e-s0s2.md` 附录 A），问题与输出格式不变。P-strict 只跑 Z。
- **每条题的 unit**：L 4 ＋ P 4 ＋ M 4 ＋ P-strict 1 ＝ 13。正式集 320 × 13 ＝ 4,160 unit／配置；开发集 80 × 13 ＝ 1,040。

### 3.3 L 任务的标签分数 q

- **Z、DAP**（答案在输出开头）：在标签词第一个字母所在的位置读 True、False、Unknown 三个候选的机率（输出直接以标签词开头时就是第一个生成位置；先生成了引号等分隔符时，前缀包括它们），归一后得 q_True 等。只有当标签词所在的 token 是输出里第一个含字母的 token 时才计分（否则如「It is not True」记计分缺失，标签照记），使各题的 q 只条件于提示与分隔符；前导分隔符的种类另记，敏感度分析只用无前导的子集重算。候选首 token 集合每个模型冻结一份，不随单题输出改变（`brief-e-s0s2.md` 5.2、5.3）。
- **CoT、CF**（输出为带 "label" 键的 JSON）：叫「**生成推理条件下的标签分数**」。先贪婪生成全文；再按冻结的 token 前缀规则（截到 label 值中标签词第一个字母所在的 token 之前）读三个候选的机率。冻结：字段顺序（label 若先于推理出现，记格式异常）、重复键与 JSON 格式异常的处理、标签边界落在 token 内部时的规则。这个分数条件于已生成的推理，不是对所有推理路径求和，**不和 Z、DAP 的 q 作机制比较**；H5 的主检验因此用 P 任务（第 4 节）。
- **计分实现规则**（交 e，送 c 审；旧 `local_subject.py` 的 `score_strings` 只认 Yes／No、多 token 会报错，`_top` 只给 top-N，不能直接改词沿用）：
  - **主读数用首 token**：计分位置是**标签词第一个字母所在的 token**（前缀包括已经生成的引号、空格等分隔符；c 审工程任务书时用真实分词器发现，若在引号之前计分，三个标签共用引号 token，集合必然相交；a 的探针确认 Qwen3 在此规则下三个标签的首 token 两两不相交，`brief-e-s0s2.md` 第 5.2 节）。每个标签列出变体串（大小写、前导空格），按各模型的分词器在上下文中取各变体的首 token，同一标签内去重，只收含字母的 token；三个标签的首 token 集合必须两两不相交（每个模型、每个输出位置在 S2 核对；相交就该位置记「计分不适用」并在冻结前改规则）。标签质量 m_label ＝ 该标签首 token 集合的机率之和；q_True ＝ m_True ／（m_True＋m_False＋m_Unknown）。只算首 token、不计后续 token 与终止边界，冻结稿写明这是「首 token 标签分数」。
  - 读未经采样器处理的机率（`post_sampling_probs=false`），用 log 空间计算，避免下溢。
  - 首 token 不在 top-N 内时**不当成 0**：其机率落在 [0, top-N 末位机率] 之间，记「有界读数」，先逐标签把去重后各首 token 的机率上下界加总，得 m_True ∈ [a, b]、m_False ∈ [c, d]、m_Unknown ∈ [e, f]，再取 q_True 的保守区间 q_L ＝ a／(a ＋ d ＋ f)、q_U ＝ b／(b ＋ c ＋ e)（q 对 m_True 单调递增、对另两者单调递减）；分母为 0 时记计分缺失；有界读数在缺失界限分析中按区间两端代入（4.2）。三个标签的首 token 都不在 top-N 内时记「计分缺失」。两者分开计数。「完整读数」指三个标签去重后的**全部**首 token 都在 top-N 内。
  - 每个模型、每个输出位置分别做单元测试；开发集报告完整读数的比例。
- 原始 logprob 全部保存；主分析不对 q 四舍五入，不加随机扰动打破并列。

## 4 实验 1：指标与假设

- **尺度**：一律换成百分尺度 0–100（q × 100；口述机率按报告值）。「点」指百分尺度上的 1 点；端点＝ ≤ 5 或 ≥ 95。
- **AUC(D > C)**：正式集 80 条 D 与 80 条 C 的 Mann–Whitney AUC，并列按半计。同时报告：不同分数值的个数、C–D 跨组并列率、数值精度。**解释限定**：D 与 C 没有共同动词（C／D 前提平均 5.78／4.72 词，假设 4.74／3.71 词，c 由原数据算出），AUC 只叫「该基准上的组间分离度」，包含体貌、词汇与句面差异。
- **配对差**：每簇 C_i − A_i、D_i − B_i；**差中差** DiD ＝ mean(C − A) − mean(D − B)，减少固定词汇水平的影响，但两类中断内容不同，不解释为纯粹的终结性因果效应。

### 4.1 确认性假设（每配置一个家族，共 10 项，α = 0.05）

| 编号 | 统计量 | 任务／提示 | 零假设与侧 | 结论用语 |
|---|---|---|---|---|
| H1 组间分离度 | AUC(D>C) − 0.5 | P／Z | ≤ 0，单侧 | 方向确认；区间下界 > 0.10（即 AUC > 0.60）另称「超过阈值」 |
| H2 终结中断差 | mean(C − A) | P／Z | ≤ 0，单侧 | 方向确认；下界 > 10 点称「超过阈值」 |
| H3 差中差 | DiD | P／Z | ≤ 0，单侧 | 同 H2 |
| H4a 输出协议 | AUC_P-strict − AUC_L(q) | Z | ＝ 0，双侧 | 方向；区间在 ±0.05 内称「等效（±0.05）」 |
| H4b 问题框架 | AUC_P − AUC_P-strict | Z | ＝ 0，双侧 | 同 H4a |
| H5_DAP、H5_CoT、H5_CF | ΔAUC_k ＝ AUC_k − AUC_Z | P | ＝ 0，双侧 | 见下 |
| H6a 接口：分离度 | AUC_M − AUC_P | Z | ＝ 0，双侧 | 同 H4a |
| H6b 接口：端点 | C 组端点率_P − 端点率_M | Z | ≤ 0，单侧 | 方向确认；下界 > 10 个百分点称「超过阈值」 |

- **两类声明、两种保护**：
  - **方向声明**（拒绝表中的零假设）：10 项点零假设检验，用 Holm 控制家族错误率。
  - **阈值声明与等效声明**（「超过阈值」「等效（±0.05）」）：用 **Bonferroni 同时区间**，每项双侧水平 1 − 0.05／10（即 99.5%），10 项一起保护。阈值声明看区间靠近零的端点是否越过阈值；等效声明看整个区间是否落在 (−0.05, 0.05) 内。
  - 两类声明分开判读，可以同时成立，照实并列报告。
- **H5 的判读**（只描述测量，不推断机制）：方向与等效**分别**判读，例如可报告「分离度有小幅提高（Holm），同时在 ±0.05 的等效界内（Bonferroni 区间）」。方向：拒绝 ΔAUC ＝ 0 且点估计 > 0 →「分离度提高」，< 0 →「分离度降低」；未拒绝 → 不作方向声明。等效：Bonferroni 区间整个在 (−0.05, 0.05) 内 →「与零样本等效（±0.05）」。两者都不成立 →「证据不足」。
- **分数位置** ΔLoc_k（C、D 合并后平均分数的变化）与各提示下的三标签比例**只作描述**，附区间，不进判读。
- 「方向确认」＝ Holm 下拒绝零假设；「超过阈值」＝ Bonferroni 区间靠近零的端点越过阈值。单侧检验落在反方向时不算拒绝，另作描述。
- **H1、H2 只在 P 任务上作确认**；L（q 与实际标签）、P-strict、M 上的同一量全部描述性报告。

### 4.2 统计方法

- **整簇 bootstrap**：终结簇与非终结簇**分层**各自重抽（各 80 簇），每个簇带上该簇两条题的全部任务与提示，保留同一题跨条件的对应；B ＝ 5,000，固定种子，不插值分位数区间。
- **p 值**（百分位 bootstrap）：单侧「> 0」的零假设 p ＝（1 ＋ #{θ*_b ≤ 0}）／（B ＋ 1）；「< 0」反之；双侧 p ＝ min(1, 2 × 两个单侧 p 的较小者)。Holm：10 个 p 值由小到大排序，第 j 个与 0.05／(10 − j ＋ 1) 比较，遇到第一个不拒绝即停；p 值相等时按假设编号顺序。
- **Bonferroni 同时区间**：每项取 bootstrap 分布的 0.25% 与 99.75% 分位数（双侧 99.5%）。
- **推断是近似的，冻结前先验证**（c 第三轮用一个反例说明：稀有尾部下，80 簇全部抽不到尾部值的机率可达约 45%，百分位 bootstrap 会给出极小 p 值与退化区间）：
  - **退化规则**：某项的 bootstrap 分布不同取值少于 20 个，或其 0.25%–99.75% 区间宽度为 0，该项不作任何确认性声明，标「证据不足（重抽分布退化）」；此时该项的确认性区间定义为整个参数域（例如 AUC 差为 [−1, 1]），p 值记为 1。有缺失时，下界版与上界版两个重抽分布**任一**退化即判退化。
  - **模拟验证**（S4 之后、冻结之前，由 e 实现、送 c 审）：
    - 情景：开发集的经验分布、强偏斜分布、稀有尾部（如 1% 的簇取极端值）、大量并列与端点堆积、2% 缺失；每个情景至少 2,000 次模拟实验，报告模拟误差（二项标准误）。
    - 效应设定：(a) 全部零假设成立；(b) 部分零假设成立（其余项设为真实效应）；(c) **声明边界**：H1 的 AUC ＝ 0.60、H2／H3 的 10 点、H6b 的 10 个百分点、H4／H5／H6a 的 ΔAUC ＝ ±0.05，以及这些边界附近（边界 ± 半个模拟标准误的若干点）。
    - 验证对象是**最终声明规则**（Holm 方向声明、Bonferroni 阈值与等效声明、退化规则、缺失保护一起），不是单项检验。
    - 单项筛查标准：名义 α ＝ 0.05 的误拒率 ≤ 0.075，名义 0.005 的误拒率 ≤ 0.0075，99.5% 区间覆盖率 ≥ 0.99。这只是筛查。
    - 家族标准：完整 Holm 流程的家族误拒率（至少一次错误的方向声明）≤ 0.05 ＋ 2 个模拟标准误；10 项区间的**同时**覆盖率 ≥ 0.95 − 2 个模拟标准误；边界情景下错误宣告「超过阈值」或「等效」的比例 ≤ 0.05 ＋ 2 个模拟标准误。
    - 覆盖率的分母是**全部**模拟实验：退化的实验按上面的定义（整个参数域）计入，不删除；另报退化率，以及非退化实验的条件覆盖率。
    - 冻结稿里关于保护水平的措辞，按验证实际达到的水平写，不写高于验证结果的说法。
  - 不通过的统计量：改用有依据的替代方法（如学生化 bootstrap，或 AUC 的簇稳健方差法），并用同一组情景重新验证；仍不通过就降为描述。处理结果写入冻结稿，**不靠只加大 B 来过关**。
- **缺失**：分别报告生成、解析、计分三种可用率。
  - 传输错误（连不上服务、超时）：同一提示重试，最多 3 次。
  - 格式失败（贪婪解码下重试结果相同）：不重试，直接记缺失；不得换提示或解码。
  - 缺失界限（有界读数按其区间两端同样处理）：
    - 单个量：均值以 0／100 代入；端点率以 0／1 代入；AUC 把缺失的 D 记为 0、缺失的 C 记为 100 得下界 L，反之得上界 U。
    - 差值 θ ＝ f₁ − f₀：下界 ＝ L₁ − U₀，上界 ＝ U₁ − L₀。配对差 C − A、D − B 与差中差按每一项的系数正负分别取对结论最不利的端点（系数为正的项取其下界算整体下界，系数为负的项取其上界）。
    - 在 bootstrap 中：每个重抽样本分别算「最不利下界版」与「最不利上界版」的统计量；受保护区间 ＝［下界版分布的下分位数，上界版分布的上分位数］，p 值：单侧「> 0」用下界版分布，单侧「< 0」用上界版分布；双侧 p ＝ min(1, 2 × min(p₊, p₋))，其中 p₊ 由下界版分布中 ≤ 0 的比例算、p₋ 由上界版分布中 ≥ 0 的比例算；再进入 Holm。
    - 方向声明只看上述 p 值经 Holm 是否拒绝（不另加区间门槛）；阈值声明要求受保护的 Bonferroni 区间靠近零的端点越过阈值；等效声明要求受保护区间的**两端**都在等效界内。界限跨过判读边界的标「证据不足（缺失）」，并另报完整题子集的结果。
- **功效**：开发集后做情景模拟，覆盖条件间相关、并列、端点、缺失与 Holm。80／80、连续分数、零效应下普通 AUC 的标准误约 0.046（c 估算），ΔAUC 的功效还取决于条件间相关。**等效界 ±0.05 不依开发集结果调宽**；功效不足就把对应假设降为描述，在冻结前写明。

## 6 实验 2：中文版（纲要，S4 之后细化成 `exp2-zh/PLAN-E2.md`）

- **材料自编**（不翻译 ImperfectiveNLI）：由 Claude 撰写（用户偏好），用户审读。用户审读的定位是**材料检查**，不当人类基线（c 提问 25 的默认，待用户确认）。
- **事件与论元固定**：前提与假设用同一时间状语和有定名词组绑定同一事件，例如前提「那天下午，木匠正在盖一座凉亭。」、假设「那天下午，木匠盖好了那座凉亭。」进行体固定用「正在」。每类动词逐一规定完整动词短语、宾语与「了」的位置（终结性不只看裸动词，宾语与补语也参与）。
- **因素**：
  - 终结类：前提 ×｛无中断、中断｝× 假设｛结果补语＋了（盖好了）、光杆 V了（盖了）｝；
  - 非终结类：前提 ×｛无中断、中断｝× 假设｛V了（在跑道上跑了步）｝；
  - 「V过」先不进主设计（易引出此前经历的读法、可能指另一次事件）。
  - 诊断语境（正向对照）：与假设用同一事件、同一观察期。假设固定为「那天，木匠盖好了那座凉亭。」；明确完成：「那天木匠正在盖一座凉亭，当天傍晚就盖好了。」；明确未完成：「那天木匠正在盖一座凉亭，到当天结束时还没有盖好。」用来验证材料确实能引出预期区别（主材料的前提与假设同样以「那天」为观察期）。
- **对比**：结果补语的作用定义为**终结类内部的配对对比**（同一前提下「盖好了」与「盖了」的分数差），分别对 L 与 P／M 写预测：P 任务与 M 任务（加权平均）中，无中断前提下「盖好了」的分数低于「盖了」；L 任务中两者都未被前提保证，可能都判 Unknown，相近分数在 L 上不算失败。跨动词类只比较共有形式（V了）。不写「没有利用结果补语」，只报可观测的分数差。
- **先做材料检验**：约 10 个终结、6 个非终结动词，经用户审读与诊断语境冒烟，确认材料能区分后，再扩到约 60／40（数量在功效情景后定）。
- **人类判断**：Xu & Schmitt 系列研究的量表与方法尚未读原文（待 d）。论文若需要人类基线，另定盲评设计（参与者、量表、排除、一致性），在看模型正式结果之前冻结。
- **跨语言**：中英材料、标签、提示不匹配，只报告各自语言内的结果，不作跨语言差异的确认性结论。
